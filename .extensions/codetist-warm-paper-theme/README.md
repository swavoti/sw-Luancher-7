# Warm Paper Theme

A clean near-white light theme for Codetist with a barely warm ivory tint, crisp dark text, and restrained terracotta accents.

## Palette

- Editor: near-white ivory `#fffefa`
- Sidebar: barely warm white `#fffdf9`
- Text: crisp charcoal `#292722`
- Accent: terracotta `#a95335`
- Selection: soft warm white `#f5e9dd`
