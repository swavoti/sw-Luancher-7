# Codetist Cyber Obsidian

A high-contrast, obsidian-dark color scheme designed for Codetist IDE. Built for developers who want deep background contrast (`#0D0F12`), vibrant neon accents, and high token legibility without muted pastel tones.

---

## Theme Specs

- Editor Background: #0D0F12 (Deep Obsidian Dark Grey)
- Primary Accent / Line / Cursor: #00F0FF (Electric Cyan)
- Sidebar & UI Layering: #090A0C -> #060708
- Token Color Highlights:
  - Keywords / Storage / Modifiers: #FF477E (Neon Pink)
  - Strings: #00E676 (Vivid Spring Green)
  - Functions: #00F0FF (Cyan)
  - Numbers / Constants: #FFB703 (Amber)
  - Types & Classes: #7000FF (Deep Violet)
  - Comments: #4A5264 (Muted Steel Italic)
